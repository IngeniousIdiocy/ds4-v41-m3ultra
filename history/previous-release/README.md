# The previous release's record

These are the experiments, receipts and release notes of the previous release
(tag `v41-oct-release`, commit `eb0c342e`), built on an older DwarfStar. They
are copied here unchanged, at the same relative paths: `docs/` and `bench/` as
they were in that release.

The scripts and commands in them target that build and its switches, not this
branch, so they will not run as written against this tree. The experiments are
kept as the record of how that work was measured and what it found, including
the ideas that did not pay.
